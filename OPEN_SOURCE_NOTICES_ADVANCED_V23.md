# MotionCanvas Advanced Build V23

Added:
- Multi-frame transform engine: translation, scale, rotation, pivot and X/Y flip.
- Raster smudge/smear engine with radius and strength controls.

Open-source references used as feature references:
- Dolphin Animate — MIT
- FrameBaker — MIT
- Dream Pixel — Apache-2.0

The MotionCanvas implementations in this build are independently written Kotlin/Android code.
No upstream source code is copied into these two engines.

Important:
This ZIP contains the previous V22 project plus these V23 engine files.
The GitHub branch/PR contains the corresponding repository changes.
