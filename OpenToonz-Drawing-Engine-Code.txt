ANDROID CONNECTION
------------------
The exact OpenToonz source is the drawing implementation.
Only the Android integration boundary may be new.

Required data flow:

Android touch/stylus
        |
        v
Project Canvas input adapter
        |
        v
OpenToonz stroke input / StrokeGenerator
        |
        v
OpenToonz TStroke / raster/vector drawing
        |
        v
OpenToonz rendering/data model
        |
        v
Project Canvas rendering surface

The adapter MUST NOT reimplement the OpenToonz stroke algorithm.

FEATURE CONNECTIONS
-------------------
Brush:
Project Canvas brush controls -> OpenToonz brush/tool settings

Pressure:
Android MotionEvent pressure -> OpenToonz thick-point/brush pressure input

Smoothing:
Input points -> OpenToonz StrokeGenerator

Vector drawing:
Input -> TStroke -> TVectorImage

Raster drawing:
Input -> raster brush/stroke generator -> TToonzImage/raster data

Eraser:
Project Canvas eraser command -> OpenToonz eraser/raster editing path

Selection:
Project Canvas selection UI -> OpenToonz vector/image object model where compatible

Undo/redo:
Project Canvas history must record operations against the OpenToonz document/drawing
objects. Do not create a second independent drawing representation.

Layers:
Project Canvas layer model must map to the OpenToonz-compatible image/document
representation.

Timeline:
Timeline selects the active drawing/frame. It must not duplicate the actual stroke
algorithm.

REQUIRED BUILD STRATEGY
-----------------------
1. Vendor the required exact OpenToonz source into the Project Canvas source tree.
2. Preserve each upstream copyright/license notice.
3. Build native C++ through Android NDK/CMake.
4. Remove desktop-only source from the Android target.
5. Do not rewrite OpenToonz drawing algorithms in Kotlin.
6. Add only the minimum JNI/NDK adapter required to pass Android input and receive
   rendered/drawing output.
7. First test: draw one stroke.
8. Second test: pressure-sensitive stroke.
9. Third test: erase.
10. Fourth test: vector stroke.
11. Fifth test: save/load drawing.
12. Only after these pass, connect timeline/layers/export.
