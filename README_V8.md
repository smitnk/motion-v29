# MotionCanvas V8

Native Android Kotlin/Jetpack Compose animation editor.

## New in V8
- Custom named brush presets
- One-tap brush preset application
- Delete/replace brush presets
- Presets retain brush color, width and alpha
- GitHub Actions build workflow

The brush-preset feature is an independently written Kotlin adaptation of the feature concept documented by ToonFrame Studio, an open-source frame-by-frame animation project.

Build locally with Gradle 8.x/Android Studio or use `.github/workflows/build-apk.yml` on GitHub Actions.
