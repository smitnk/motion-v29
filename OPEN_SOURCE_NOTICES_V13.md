# MotionCanvas V13 Open-Source Notices

This release adds native Kotlin implementations inspired by documented workflows in compatible open-source projects.

- **ToonFrame Studio** — documented features used as workflow reference: flood fill, rotoscoping/video frame extraction, multi-layer animation, lasso, audio tracks, onion skin and export. See the upstream repository/license before redistributing any upstream source.
- **FrameBaker** — MIT License. Used as a reference for video frame extraction, spritesheet/timeline batch operations and chroma/matting workflows. MotionCanvas V13 implementations are independently written in Kotlin.
- **Dream Pixel** — Apache-2.0. Used as a reference for Android animation timeline, onion skin, palette/fill and local project workflows.
- **LibreCuts** — MIT License. Used as a reference for Android media-editor concepts including trimming, keyframes, audio workflows, chroma key and hardware MediaCodec export.

No proprietary source from Famanimates or SoCreate is copied into this release.
