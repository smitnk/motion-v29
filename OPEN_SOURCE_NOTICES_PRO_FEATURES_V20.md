# MotionCanvas V20 — Open-Source References / Licenses

- sameerasw/Canvas — MPL-2.0: native Kotlin/Jetpack Compose canvas, text/shape/arrow and drawing workflow references.
- SmartToolFactory/Compose-Drawing-App — MIT: Compose Canvas drawing, stroke/path, undo/redo and smoothing references.
- Android graphics APIs — Apache-2.0 platform/framework usage for Canvas, Bitmap and Porter-Duff composition.
- reearth/hokusai — MIT OR Apache-2.0: advanced brush-engine concepts such as pressure-aware dabs, spacing and scatter/jitter.

V20 integrates compatible functionality without copying Hokusai Rust source. The AdvancedBrushEngine is an independent Kotlin implementation.
