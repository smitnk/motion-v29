# Open-source references used in V12

- MotionCanvas repository branch `feature/pro-animation-timeline-integrated`: TimelineState state-machine pattern reused/adapted.
- FrameBaker: MIT; feature concepts used for motion trails, multi-select/batch timeline, per-frame duration and sprite-sheet workflows. No FrameBaker web code is embedded.
- Dream Pixel: Apache-2.0; feature concepts used for Android frame timeline, fill, palette, onion-skin and local project workflows.
- ToonFrame Studio: feature/reference source for lasso, audio tracks, layer workflow, PNG/GIF/MP4 export. Verify and preserve upstream license notices before any direct source copying.
- Famanimates and SoCreate are explicitly not copied because their repositories state proprietary/all-rights-reserved licensing.
