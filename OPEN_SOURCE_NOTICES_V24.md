# MotionCanvas V24 — Ultimate Advanced Feature Pack

Feature-reference repositories searched:
- ToonFrame Studio: lasso/transform, timeline operations, onion skin, audio tracks, rotoscope and export concepts. See https://github.com/vineetp6/toonframe_studio
- Dolphin Animate: tweening, motion guides, free transform and sprite/GIF/PNG/MP4 export concepts. MIT. See https://github.com/Agony270313/Dolphin-Animate
- FrameBaker: multi-source import, onion-skin editing, skeletal motion, keyframe transforms and spritesheet workflows. See https://github.com/taotao7/FrameBaker
- Dream Pixel: Android animation timeline, selection, onion skin, PNG export. Apache-2.0. See https://github.com/suredesm/dream-pixel
- Klecks: pressure/stabilizer brushes, smudge and touch drawing concepts. MIT. See https://github.com/bitbof/klecks
- OpenToonz: reference for motion tweening, skeleton rigging, particles and production animation concepts. See https://github.com/opentoonz-2d-animation/

This V24 package adds independently implemented Kotlin engine modules for:
- Graph/keyframe interpolation
- Exposure/timing tracks
- Polygon/rectangle selection
- Magic wand selection
- Liquify push
- Particle emission/stepping
- IK bone-chain solving
- 2D camera state
- Audio waveform downsampling
- Crash-safe autosave
- Sprite-sheet layout planning
- Feature manifest

Existing V23 engines are retained:
- Multi-frame transform
- Smudge/smear
