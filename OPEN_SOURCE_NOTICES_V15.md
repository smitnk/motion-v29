# MotionCanvas V15 Open-Source Notices

## AndroidX Media3 / AOSP
Media pipeline design and API usage are based on AndroidX Media3 / Android Open Source Project material, licensed under Apache License 2.0. The implementation in MotionCanvas uses Android platform MediaExtractor/MediaMuxer for the export path and does not copy proprietary source.

## Rotoscoping
The video-to-frame pipeline uses Android's MediaMetadataRetriever API. The workflow is conceptually aligned with open-source animation editors that support video frame import; no GPL/proprietary source was copied into MotionCanvas.

See the Android Open Source Project licensing page and AndroidX Media3 documentation for license/API references.
