# V13 Feature Integration

- Audio trim in/out points and fade envelopes with `AudioTimelineEngine`.
- Video-to-reference-frame extraction using Android `MediaMetadataRetriever`.
- Chroma-key removal with tolerance and edge-softness controls.
- Reference smudge engine for local paint blending.
- Batch frame duplicate/delete/duration operations.
- Keyframe interpolation/easing utility.
- Pro Tools panel wired into the editor toolbar.
- Existing V12 timeline, waveform, sprite-sheet, motion-trail and voice-recording features remain available.
