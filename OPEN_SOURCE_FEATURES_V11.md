# Open-source feature integrations — V11

- Timeline state machine adapted from the public `feature/pro-animation-timeline-integrated` branch in the MotionCanvas repository.
- Motion trails, sprite-sheet export, multi-frame timing UI and waveform preview are independently implemented from documented open-source feature concepts.
- Feature references include ToonFrame Studio (open source), Dream Pixel (Apache-2.0), and FrameBaker (MIT).
- No proprietary Famanimates or SoCreate source is copied.
- FrameBaker MIT license permits reuse subject to its license notice; ToonFrame/Dream Pixel licenses must be retained if upstream code is later copied directly.
