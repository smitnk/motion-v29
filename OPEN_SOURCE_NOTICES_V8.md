## ToonFrame Studio
Repository: https://github.com/vineetp6/toonframe_studio

MotionCanvas V8 adapts the feature concepts and data-flow approach for custom brush presets from ToonFrame Studio's open-source animation editor. The upstream project documents custom brush presets as named style + color + width combinations.

License: verify the repository's current LICENSE before redistributing upstream-derived source. This MotionCanvas integration uses a small independently written Kotlin implementation rather than copying the upstream Flutter source verbatim.
