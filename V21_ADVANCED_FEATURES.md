# MotionCanvas V21

Two remaining advanced features added:

1. Multi-frame timeline operations
   - Range selection
   - Duplicate range
   - Delete range
   - Move range
   - Frame hold editing

2. Direct reference transform interaction
   - Ref Edit mode
   - One-finger pan/move
   - Pinch zoom
   - Rotation
   - Opacity control
   - Reference lock
   - Reset transform

The batch-operation API now matches the UI calls used by MainActivity.
