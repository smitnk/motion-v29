# MotionCanvas Open-Source Notices

## SmartToolFactory/Compose-Drawing-App
Used as a reference/adapted technique for quadratic-Bezier midpoint stroke smoothing.
License: MIT.
Repository: https://github.com/SmartToolFactory/Compose-Drawing-App

## Android Stylus APIs
MotionCanvas uses Android/Jetpack Compose pointer input APIs for stylus pressure. The implementation reads PointerInputChange.pressure and PointerType.Stylus and does not bundle third-party stylus code.

Reference: https://developer.android.com/develop/ui/compose/touch-input/stylus-input/advanced-stylus-features
