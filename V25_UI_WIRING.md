# V25 UI Wiring

The V24 engines are now exposed through:
- `AdvancedFeatureController`
- `AdvancedToolsPanel`
- `MainActivity` advanced-state wiring

The panel provides live controls for:
keyframes, exposure/holds, camera zoom, smudge controls, liquify strength,
multi-frame flip/rotation state, IK controller entry, and particle emission.

Existing V24 engine modules remain in the project.
