# Open-source notices — V10

- **sameerasw/Canvas** — MPL-2.0. Used as a reference for native Android canvas/editor interaction concepts such as text, shapes, arrows, and transform-oriented editing. MotionCanvas code remains separately implemented.
- **ToonFrame Studio** — public open-source animation editor used as a feature-reference source for lasso, fill, audio, reference/rotoscope, timeline and frame-editing workflows. No upstream Flutter source is copied into MotionCanvas V10. Verify the repository's current LICENSE before redistributing any upstream-derived code.
- **SmartToolFactory/Compose-Drawing-App** — MIT. Existing MotionCanvas stroke-smoothing approach is independently adapted from its documented quadratic/midpoint smoothing technique.
- **MohamedRejeb/compose-stylus** — Apache-2.0. Existing MotionCanvas stylus/pressure architecture uses its public API concepts.

All new V10 integrations are written in Kotlin/Jetpack Compose for MotionCanvas.
