# MotionCanvas V7

Added:
- Native text objects on animation frames.
- Tap the Text tool, tap the canvas, enter text, choose text size, and place it at the tapped canvas position.
- Text objects render with the active color and participate in the frame model.
- Open-source TextItem model pattern adapted from sameerasw/Canvas under MPL-2.0 with attribution.

Still requiring deeper integration:
- Select/move/scale individual text objects.
- Crop UI with draggable crop bounds.
- Full persistent project database/autosave for all frame content.
- Audio waveform rendering and final audio/video muxing.
